Adds **Link to content** to the editor's link input, in both the selection bubble menu and the toolbar popover. It opens the same content picker the menu editor uses, so an editor can link body text to a page or post on the site by choosing it rather than typing its URL. The link is the entry's public URL from its collection's `urlPattern`; an entry with no slug has no URL and is not applied.
