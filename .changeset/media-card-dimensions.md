Adds an image's dimensions to the media cards in the Media Library and the media picker, so an editor can see whether an image is large enough before choosing it. Grid cards show them beside the format under the filename, list rows in the picker add them after the file size, and the Media Library's list view has a **Dimensions** column. Items without a stored width and height, such as documents, show none. Wherever the admin shows an image's dimensions, it writes them in the digits of the admin's language, so Persian and Bengali show their own digits.
