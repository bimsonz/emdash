The visual editor now edits columns blocks on the page, where they showed as a card reading "Plugin block: columns (edit in admin)". A columns block shows as it is published, its columns side by side, or stacked on a narrow screen, and the blocks in each column can be edited in place: text, headings, lists, quotes, links, alignment and images. A label names the layout and the column being edited. The layout itself, adding, moving, resizing and deleting columns, is still changed in the admin editor, so nothing done on the page adds or removes a column.
